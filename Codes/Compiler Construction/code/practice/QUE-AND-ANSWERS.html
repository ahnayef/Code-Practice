Set 1 — Fundamental scanning

Time: 60 minutes · Answer all five questions · 50 marks

1.1 · 10 marks

Write a flex program that reads a sequence of words and integers and prints one line for each token, in the order in which it appears. A word must be printed as Word: <text> and an integer as Integer: <number>. Any other character must be ignored.

Sample Input
alpha 42 beta 7

Sample Output
Word: alpha
Integer: 42
Word: beta
Integer: 7

Answer

%{
#include <stdio.h>
%}
%option noyywrap
%%
[a-zA-Z]+   { printf("Word: %s\n", yytext); }
[0-9]+      { printf("Integer: %s\n", yytext); }
.|\n        ;
%%
int main(void) { yylex(); return 0; }

The catch-all rule . and \n with an empty action swallows everything that is not a word or an integer.

1.2 · 10 marks

Write a flex program that reads the file input.txt, counts the number of words, the number of integers, and the number of characters that are neither letters, nor digits, nor white space, and prints the three counts at the end with the headings Words, Integers and Others. If the file cannot be opened, the program must print File not found! and terminate.

Sample Input (contents of input.txt)
a 1 b 2 ;

Sample Output
Words: 2
Integers: 2
Others: 1

Answer

%{
#include <stdio.h>
int words = 0, ints = 0, others = 0;
%}
%option noyywrap
%%
[a-zA-Z]+            { words++; }
[0-9]+               { ints++; }
[ \t\n]              ;
[^a-zA-Z0-9 \t\n]    { others++; }
%%
int main(void)
{
    FILE *f = fopen("input.txt", "r");
    if (!f) { printf("File not found!\n"); return 1; }
    yyin = f;
    yylex();
    printf("Words: %d\nIntegers: %d\nOthers: %d\n", words, ints, others);
    fclose(f);
    return 0;
}

yyin is pointed at the file before yylex() runs; failing fopen is the only path that prints File not found!.

1.3 · 10 marks

Write a flex program that prints every word and every integer of the input together with its length, in the form <token>(<length>), without any space between consecutive tokens.

Sample Input
int xy 12345

Sample Output
int(3)xy(2)12345(5)

Answer

%{
#include <stdio.h>
%}
%option noyywrap
%%
[a-zA-Z]+   { printf("%s(%d)", yytext, yyleng); }
[0-9]+      { printf("%s(%d)", yytext, yyleng); }
.|\n        ;
%%
int main(void) { yylex(); printf("\n"); return 0; }

yyleng is the length of the token, so no string length call is needed; the final newline is printed once after yylex().

1.4 · 10 marks

Write a flex program that reads one word per line and prints, for each line, the word in reverse followed by its length in brackets. Line numbers must not appear in the output.

Sample Input
abc
hello

Sample Output
cba(3)
olleh(5)

Answer

%{
#include <stdio.h>
#include <string.h>
%}
%option noyywrap
%%
^[a-zA-Z]+$  {
                int i;
                for (i = yyleng - 1; i >= 0; i--) putchar(yytext[i]);
                printf("(%d)\n", yyleng);
             }
.|\n         ;
%%
int main(void) { yylex(); return 0; }

^...$ makes the match a whole line, so the newline never enters yytext and yyleng is the length of the word.

1.5 · 10 marks

Write a flex program that scans the input until the word stop is encountered as a complete word. It must print Token: <text> for every word and integer seen before it, followed by Total: <n> where <n> is the number of tokens printed. Any input after the word stop must be completely ignored.

Sample Input
a 1 b stop c 2

Sample Output
Token: a
Token: 1
Token: b
Total: 3

Answer

%{
#include <stdio.h>
#include <string.h>
int total = 0;
%}
%option noyywrap
%%
[a-zA-Z]+   {
                if (strcmp(yytext, "stop") == 0) {
                    printf("Total: %d\n", total);
                    return 0;
                }
                printf("Token: %s\n", yytext);
                total++;
            }
[0-9]+      { printf("Token: %s\n", yytext); total++; }

int main(void) { yylex(); return 0; }

Reaching stop prints the total from inside the action and returns from yylex, which is the simplest way to stop scanning.

Set 2 — Tokenizing a C program

Time: 75 minutes · Answer all five questions · 60 marks

2.1 · 15 marks

Write a flex program that reads a C program and prints every token with its class, in the form <token> --> <class>. The classes are KEYWORD, IDENTIFIER, INTEGER, FLOAT, OPERATOR, PUNCTUATION and STRING. Treat int, float, char, double, void, if, else, while, for, return as keywords; ( ) { } [ ] ; , . as punctuation; + - * / % = < > ! & | and their two-character combinations as operators. White space and comments must produce no output.

Sample Input
int x = 3.5; // rate

Sample Output
int --> KEYWORD
x --> IDENTIFIER
= --> OPERATOR
3.5 --> FLOAT
; --> PUNCTUATION

Answer

%{
#include <stdio.h>
%}
%option noyywrap
KW      int|float|char|double|void|if|else|while|for|return
OP      (\+\+|--|<<=|>>=|==|!=|<=|>=|&&|\|\||[+\-*/%=<>!&|])
PUNCT   [(){}\[\];,.]
%%
"//".*                  ;
"/*"([^*]|\*+[^*/])*\*+"/"  ;
\"([^\"\\]|\\.)*\"      { printf("%s --> STRING\n", yytext); }
[0-9]+\.[0-9]+          { printf("%s --> FLOAT\n", yytext); }
[0-9]+                  { printf("%s --> INTEGER\n", yytext); }
{KW}                    { printf("%s --> KEYWORD\n", yytext); }
[a-zA-Z_][a-zA-Z0-9_]*  { printf("%s --> IDENTIFIER\n", yytext); }
{PUNCT}                 { printf("%s --> PUNCTUATION\n", yytext); }
{OP}                    { printf("%s --> OPERATOR\n", yytext); }
[ \t\n]                 ;
.                       ;
%%
int main(void) { yylex(); return 0; }

Keywords must be listed before the identifier rule, otherwise int matches as an identifier by the longest-match-then-earlier-rule rule.

2.3 · 15 marks

Write a flex program that reports the position of every token. For each token print line <L> col <C> <text>, where the line and the column are both counted from 1 and the column is the position of the first character of the token.

Sample Input
int x
  y;

Sample Output
line 1 col 1 int
line 1 col 5 x
line 2 col 3 y
line 2 col 4 ;

Answer

%{
#include <stdio.h>
int line = 1, col = 1;
static void advance(void)
{
    int i;
    for (i = 0; yytext[i]; i++) {
        if (yytext[i] == '\n') { line++; col = 1; }
        else col++;
    }
}
%}
%option noyywrap
%%
[ \t]+          { advance(); }
\n              { advance(); }
"//".*          { advance(); }
[a-zA-Z_][a-zA-Z0-9_]*  { printf("line %d col %d %s\n", line, col, yytext); advance(); }
[0-9]+          { printf("line %d col %d %s\n", line, col, yytext); advance(); }
[(){}\[\];,.]   { printf("line %d col %d %s\n", line, col, yytext); advance(); }
[+\-*/%=<>!&|]  { printf("line %d col %d %s\n", line, col, yytext); advance(); }
.               { advance(); }
%%
int main(void) { yylex(); return 0; }

flex keeps yylineno but not a column, so a helper advances line and col over yytext after each token is printed.

Write a flex program that builds a frequency report of token classes. After scanning, it must print exactly six lines in this order: Keywords, Identifiers, Integers, Floats, Operators, Punctuations, each followed by a colon and the count.

int a = 1;

Keywords: 1
Identifiers: 1

Set 3 — Identifiers, keywords and declared names

Time: 60 minutes · Answer all five questions · 55 marks

3.1 · 10 marks

Write a flex program that treats every line of the input as a single candidate and decides whether it is a valid C identifier. A valid identifier begins with a letter or an underscore and continues with letters, digits or underscores only. Print Valid or Invalid.

Sample Input
_x9
9x

Sample Output
Valid
Invalid

Answer

%{
#include <stdio.h>
%}
%option noyywrap
%%
^[a-zA-Z_][a-zA-Z0-9_]*$  { printf("Valid\n"); }
\n                        ;
^.*\n                     { printf("Invalid\n"); }
.|\n                      ;
%%
int main(void) { yylex(); return 0; }

Two whole-line rules: the identifier shape prints Valid, and any other non-empty line prints Invalid before the newline rule clears the line.

3.2 · 10 marks

Write a flex program that classifies each word of the input as Keyword, Identifier or Invalid. The keywords are auto break case char const continue default do double else enum extern float for goto if int long register return short signed sizeof static struct switch typedef union unsigned void volatile while. A word that is not a valid identifier is Invalid.

Sample Input
int count 2x

Sample Output
Keyword
Identifier
Invalid

Answer

%{
#include <stdio.h>
#include <string.h>
static const char *keywords[] = {
 "auto","break","case","char","const","continue","default","do","double","else",
 "enum","extern","float","for","goto","if","int","long","register","return",
 "short","signed","sizeof","static","struct","switch","typedef","union",
 "unsigned","void","volatile","while", NULL };
static int is_keyword(const char *s)
{
    int i;
    for (i = 0; keywords[i]; i++) if (strcmp(s, keywords[i]) == 0) return 1;
    return 0;
}
static int valid_identifier(const char *s)
{
    int i;
    if (!(s[0] == '_' || (s[0] >= 'a' && s[0] <= 'z') || (s[0] >= 'A' && s[0] <= 'Z')))
        return 0;
    for (i = 1; s[i]; i++)
        if (!(s[i] == '_' || (s[i] >= 'a' && s[i] <= 'z') ||
              (s[i] >= 'A' && s[i] <= 'Z') || (s[i] >= '0' && s[i] <= '9')))
            return 0;
    return 1;
}
%}
%option noyywrap
%%
[a-zA-Z0-9_]+  {
                 if (is_keyword(yytext))            printf("Keyword\n");
                 else if (valid_identifier(yytext)) printf("Identifier\n");
                 else                               printf("Invalid\n");
               }
[ \t\n]        ;
.              ;
%%
int main(void) { yylex(); return 0; }

Keyword test first, identifier shape second, everything else Invalid - the order matters because int and main both match the word rule.

3.3 · 10 marks

Write a flex program that recognises the keywords int, float, if, else, while, for and return in any combination of upper and lower case, and prints each one in its standard lower-case form preceded by Keyword:. Every other word must be printed as Identifier: <word> exactly as it was written.

Sample Input
INT Total WhIlE

Sample Output
Keyword: int
Identifier: Total
Keyword: while

Answer

%{
#include <stdio.h>
#include <string.h>
#include <ctype.h>

%option noyywrap

[a-zA-Z_][a-zA-Z0-9_]*  {

.                       ;
%%
int main(void) { yylex(); return 0; }

strcasecmp compares without case, and the keyword is printed from the table so the output is always lower case.

3.4 · 15 marks

Write a flex program that prints every distinct identifier of the input exactly once, in the order of its first appearance, followed by the number of the line on which it first appeared.

Sample Input
a b
a c

Sample Output
a 1
b 1
c 2

Answer

%{
#include <stdio.h>
#include <string.h>
char names[200][64];
int  first[200];
int  n = 0;
%}
%option noyywrap yylineno
%%
[a-zA-Z_][a-zA-Z0-9_]*  {
    int i;
    for (i = 0; i < n; i++) if (strcmp(names[i], yytext) == 0) break;
    if (i == n) { strcpy(names[n], yytext); first[n] = yylineno; n++; }
}
[ \t\n]                 ;
.                       ;
%%
int main(void)
{
    int i;
    yylex();
    for (i = 0; i < n; i++) printf("%s %d\n", names[i], first[i]);
    return 0;
}

%option yylineno gives the line number; a table keeps first-seen order, and the loop only prints identifiers, never keywords.

3.5 · 10 marks

Write a flex program that considers an identifier declared when it is immediately preceded by the keyword int. It must print Declared: <name> at the point of declaration and Use before declaration: <name> whenever an identifier appears that is not yet declared. Nothing is printed for keywords and numbers.

Sample Input
a = 1; int a; a = 2;

Sample Output
Use before declaration: a
Declared: a

Answer

%{
#include <stdio.h>
#include <string.h>
char declared[200][64];
int  ndecl = 0;
int  expect_decl = 0;
static int is_declared(const char *s)
{
    int i;
    for (i = 0; i < ndecl; i++) if (strcmp(declared[i], s) == 0) return 1;
    return 0;
}
%}
%option noyywrap
%%
"int"                   { expect_decl = 1; }
[a-zA-Z_][a-zA-Z0-9_]*  {
    if (expect_decl) {
        strcpy(declared[ndecl++], yytext);
        printf("Declared: %s\n", yytext);
        expect_decl = 0;
    } else if (!is_declared(yytext)) {
        printf("Use before declaration: %s\n", yytext);
    }
}
[0-9]+                  ;
[ \t\n]                 ;
.                       ;
%%
int main(void) { yylex(); return 0; }

A flag set by int tells the next identifier that it is being declared; the declared table answers every later use.

Write a flex program that classifies every integer constant of the input as Decimal, Octal or Hexadecimal, printing the class followed by the constant. A constant beginning with 0x or 0X is hexadecimal, one beginning with 0 and containing further digits is octal, and everything else is decimal.
